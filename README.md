# vin-rouge v2 — 酒类分销进销存

当前版本：**v2.7.0**（2026-11-25，见 [版本演变](#版本演变)）

单人起步、多管理员共用的极简进销存：FastAPI + SQLite，单文件 `app.py` + 单文件 `static/index.html`，依赖只有 fastapi、uvicorn、pillow。

> 版本规则（单点管理）：唯一版本源是 `app.py` 里的 `APP_VERSION`。升版时只改它，再在下面 [版本演变](#版本演变) 加一条记录；前端页脚、登录页、`/api/version`、`/api/config` 都会自动同步，不要在别处手写版本号。

## 部署

```bash
git clone https://github.com/Tao314/vin-rouge.git /opt/vin-rouge
cd /opt/vin-rouge
bash install.sh
```

`install.sh` 会做：建虚拟环境并装依赖、写 systemd 服务 `vin-rouge`、启动服务。服务监听 `127.0.0.1:9000`，访问 http://127.0.0.1:9000。对外访问请在前面加 Nginx 或 Caddy 反代并配 HTTPS，例如 Caddyfile：

```
your.domain {
    reverse_proxy 127.0.0.1:9000
}
```

本地开发运行（不用 install.sh）：

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/uvicorn app:app --host 127.0.0.1 --port 9000
```

默认端口 9000；改端口不用改代码，设环境变量 `PORT` 即可。

## 首次登录

首次使用没有默认账号：打开页面注册首位管理员（用户名 + 密码，密码至少 6 位），注册后即关闭注册；后续管理员由首位管理员在“用户管理”里生成。

## 功能

- 登录 + 用户管理：用户名+密码登录，密码 PBKDF2 加盐哈希存储；任何管理员都能新增、改名、重置密码、停用管理员账号；**所有管理员权限相同，不分角色，都能看到进价、利润和全部功能**；关键操作写 `audit_logs`，页面可查最近操作记录。
- 首页：今天销售额、今天毛利估算、客户欠款合计、供应商欠款合计、低库存提醒（库存 <5 瓶）、本月自饮 / 赠送 / 破损 / 折扣统计。
- 酒库：条码、名称、品牌、规格、容量、度数、产地、厂家、图片上传（`uploads/`，jpg/png/webp，≤5MB）、说明手写；扫条码调网上接口自动带回信息。
- 多仓库；供应商 / 客户分开管理（新增、改、停用、删除，无单可删，欠款余额自动算；客户页显示累计获赠瓶数和成本）。
- 库存补登（期初，日期可回填，成本价可空）；进货单、出货单（含物流公司 / 单号 / 运费 / 包邮记 0 / 谁付，运费与货款分开算；付款状态未付 / 部分付 / 已付，可后续补记）；出货库存不足整单拦住，不允许负库存；调拨一键。
- 出库类型：销售 / 自饮 / 赠送 / 破损。自饮、赠送、破损都减库存、不算销售收入、不产生应收，按最新进价记成本；赠送记受赠客户，可按客户查累计获赠。
- 出货折扣（只针对销售）：可填折扣率（如 0.9）或折后单价，自动算原价、折后价、折扣额；打折必须填瑕疵 / 打折原因；利润和毛利按折后实收价算；分享图显示原价、折后价、折扣额和原因。
- 分享图片：进货单 / 出货单详情页“生成分享图”，Pillow 生成 PNG（宽 1080，白底黑字，适合发微信），只做图片不做链接。出货图给客户只显示卖价，不显示进价和利润；进货图给供应商只显示进价，不显示卖价和利润。自饮 / 赠送 / 破损单不做分享图。

## 条码接口

后端 `GET /api/barcode?code=xxx`，先查本地酒库，查不到再调网上接口：

- 环境变量 `BARCODE_API_URL`（接口地址，占位即可）、`BARCODE_API_KEY`（不要硬编码，不要提交到仓库）。
- URL 为空、调用失败或查不到时返回 `{"found": false}`，前端提示手填；查到则自动填名称 / 品牌 / 规格 / 厂家 / 参考价，图片 URL 会下载保存到 `uploads/`，不热链外站。
- 覆盖说明：支持 69 开头 EAN13 国产条码；进口条码覆盖低，新品可能查不到；查不到就手填一次存本地库，下次直接用本地数据。

## 数据与备份

- 数据库：应用目录下的 `vin_rouge.db`（可用环境变量 `VIN_ROUGE_DB` 改路径）；上传图片在 `uploads/`。
- 备份：`./backup.sh`（打包 `vin_rouge.db` 和 `uploads/` 到 `backup/vin-rouge-时间戳.tar.gz`）。
- 更新：`git pull` 后装依赖、重启服务即可，数据库文件不会被覆盖：
  ```bash
  cd /opt/vin-rouge && git pull origin main && ./.venv/bin/pip install -r requirements.txt && sudo systemctl restart vin-rouge
  ```
- 分享图中文需要系统装 CJK 字体，否则中文显示为方框：`sudo apt-get install -y fonts-noto-cjk`。

## 卸载（v2.7.0）

```bash
systemctl disable --now vin-rouge
rm -f /etc/systemd/system/vin-rouge.service
systemctl daemon-reload
rm -rf /opt/vin-rouge
```

注意：旧版 v0.4.0 的服务名是 `wine-system`、数据库是 `data/wine.db`，与新版不同，不要用旧版卸载命令删新版。

## 数据模型

`users`（无 role 字段，所有管理员权限相同）、`audit_logs`、`wines`、`warehouses`、`suppliers`、`customers`、`stock`（按仓库+酒+批次唯一，库存只通过单据增减）、`inbound_orders` / `inbound_items`（type = purchase 新进货 / opening 补登期初）、`outbound_orders` / `outbound_items`（type = sale 销售 / personal 自饮 / gift 赠送 / damage 破损）、`transfers`、`payments`（补记付款 / 收款，`paid_amount` 由 payments 合计推导，`pay_status` 由此推导：0 = 未付，< 总额 = 部分付，>= 总额 = 已付；运费不计入货款总额，单独列 `freight`）。

利润按卖价减该酒最近进货成本价（或补登成本价）估算，首页显示，不做逐瓶精确批次成本核算。自饮 / 赠送 / 破损的成本同样按最新进价记。

## 版本演变

- **v2.7.0**（2026-11-25）：各页重复标题去掉：进货单、出货单、调拨、库存、酒库、供应商、客户、仓库管理、用户管理、操作记录、管理的大标题都去掉（导航高亮已能说明在哪一页）；补登的“增加库存模式”提示和用户管理的“所有管理员权限相同”留着改成小字；登录、注册、改密页标题不动。进货单物流简化：去掉包邮勾选和谁付运费，只留运费，运费始终是实际金额、肯定我方付，填 0 就是包邮；供应商欠款仍只算货款。出货单物流简化：去掉谁付运费，保留包邮勾选和运费；包邮不再把运费记成 0，运费始终是实际金额，包邮只决定谁付（选包邮我方付、不选客户付，后端按勾选自动记）；出货单总金额 = 折后货款 + 客户付的运费，欠款 = 总金额 - 已收；客户欠款合计只算客户付的那部分运费，且运费在首次确认时整单计入欠款一次（分批确认不再重复加，未确认不进欠款，废单不计）；利润扣实际运费：今日毛利 = 已确认商品毛利 − 包邮单的实际运费（客户付的运费已含在总金额里，与实际运费抵消，不重复扣；运费只扣一次，入库运费不分摊进成本）；老单保持原规则：outbound_orders 新增 freight_rule 标记（新单 1，老单 0），老单的运费付方、金额、欠款、利润都不重算，详情按原规则展示；运费输入框标签改为“实际运费”，出货单旁加提示“填写实际物流费用；包邮表示由我方承担，并非运费为 0。”，进货单旁加“固定由我方承担，不计入供应商欠款；填 0 表示无运费。”。老单据保持原样。
