# 红酒进销存系统

红酒购买 / 存储 / 销售管理。当前 v0.4.0:采购入库、批次库存、多仓调拨、应付付款、客户货单(预定/发货/公开单页)、注册与管理员、已录入信息可更改、档案分页(红酒/附件/供应商/客户/仓库各自独立页面)。

## 功能特色

- 商品档案:酒(名字/种类/年份/原产地)与附件(礼品袋/礼品盒/开瓶器/酒杯等)统一管理
- 采购入库:供应商、入库仓库、明细行(数量/进价);运费可为 0,有运费时按行金额比例分摊进批次实际成本
- 期初库存:已有库存手动录入,不产生应付
- 批次库存:库存按「批次+仓库」记账,库存流水留痕;按商品/按仓库/按批次三视图查询
- 多仓调拨:仓库间调拨只动库存位置,不产生资金变更
- 应付付款:采购自动生成应付,支持多次部分付款,余额实时可见;入库时可选已付款(应付立即全额核销)/未付款
- 客户货单:明细含酒与配件、销售/赠送行、运费三档承担(客户付/自提无/我方代付)、总计费用、物流号;发货状态与付款状态两维独立,发单可选预付;可取消(记录全保留,已发货不可取消);建单预定库存(总量/已预定/可用分开显示,超量拒绝),发货按批次先进先出真正扣库存并记批次成本
- 公开单页:每单一个不可猜链接 `/o/<token>`,客户免登录看自己的单(明细/单价/总价/总计/物流号/发货时间/状态),不显示成本;管理员一键复制链接
- 注册与管理员:全新部署时第一个注册者自动管理员;管理员可在设置里开关注册;老库升级自动迁移,老管理员账号保留
- 老库兼容:新代码直接打开老数据库自动补新表/新列(只加不删),老备份恢复后同样自动迁移
- 信息可更改:档案(商品/供应商/客户/仓库)全部字段可改;未发货货单可改客户/明细/运费(预定库存自动重算,超可用拒绝),已发货只可改物流号/备注;入库单在批次未被出库消耗时可改(批次成本与应付自动重算,新应付小于已付拒绝);调拨可改数量/目标仓(冲销原流水后重记,冲销不足拒绝);付款记录可改金额/日期/备注(已付总额重算,超应付拒绝);已取消/已作废单据不可改;每次修改在「设置 → 修改记录」留痕(改前/改后/操作人/时间)
- 防重复提交:入库/调拨单带幂等键,重复点击不重复入账
- 金额整数分存储,避免小数误差;SQLite WAL + 事务,库存扣加原子化
- 手机优先响应式页面(390px 基准),登录后使用

## 本地运行

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
WINE_ADMIN_PASSWORD='自己设一个强密码' ./venv/bin/uvicorn app:app --host 127.0.0.1 --port 9000
```

打开 http://127.0.0.1:9000

### 管理员账号

- 全新部署(全新数据库):打开页面注册第一个账号,自动成为管理员;之后默认关闭注册,管理员可在「设置」里重新开放(本期注册用户均为管理员)
- 老库升级:原管理员 `allen314`(可用环境变量 `WINE_ADMIN_USER` 改)账号与密码不变,照常登录
- 密码不写死在代码里:设了 `WINE_ADMIN_PASSWORD` 时首次启动用它建 `allen314`;老库无此账号时随机生成写在 `data/INITIAL_PASSWORD.txt`(该目录不进仓库),登录后请立即改密码并删除该文件
- 改密码:登录后「设置」页;或停服务后删库重建(会清空数据,慎用)

### 数据与备份

- 数据库:`data/wine.db`(可用 `WINE_DATA_DIR` / `WINE_DB_PATH` 改路径);上传目录 `data/uploads/`
- 备份:页面「设置 → 立即备份」,或命令行 `./backup.sh`(SQLite Online Backup,保留最近 10 份)
- 恢复:停服务,把备份文件拷回 `data/wine.db` 后重启

## 安装(VPS,Debian 13,root 模式)

```bash
git clone https://github.com/Tao314/vin-rouge.git /opt/vin-rouge
cd /opt/vin-rouge
bash install.sh
curl -s http://127.0.0.1:9000/api/me   # 应返回 {"detail":"未登录"}
```

install.sh 会做:装 python3/venv、建虚拟环境装依赖、写 systemd 服务 `wine-system`(以 root 运行,监听 127.0.0.1:9000)并启动。脚本可重复执行(幂等)。

服务只监听 127.0.0.1:9000。对外访问请在前面加 Nginx 或 Caddy 反代并配 HTTPS(域名解析与反代自行配置),例如 Caddyfile:

```
your.domain {
    reverse_proxy 127.0.0.1:9000
}
```

更新到新版:

```bash
cd /opt/vin-rouge
git pull
systemctl restart wine-system
```

纯前端改动只需 `git pull`。老数据库启动时自动迁移,数据不动。

常用运维命令:

```bash
systemctl status wine-system        # 看状态
journalctl -u wine-system -n 30 -l  # 看日志
```

## 卸载

```bash
systemctl disable --now wine-system
rm -f /etc/systemd/system/wine-system.service
systemctl daemon-reload
rm -rf /opt/vin-rouge
```

删完即干净(删除前请先备份 `data/wine.db` 与 `data/backups/`)。install.sh 装的 python3、python3-venv 等系统包可保留,不影响其他服务;反代(Nginx/Caddy)里的站点配置需自行删除。
